# Grow Happy けいけんデータベース（試作サイト）

スマホ・PC の両方に対応した、HTML / CSS / JavaScript だけで動く試作版です。
ビルドやサーバー側のプログラムは不要で、フォルダごと Web サーバーに置けば表示できます。

## ファイル構成

```
index.html      トップ（非会員）
themes.html     テーマと12 Steps（非会員も閲覧可）
plans.html      会員でできること（非会員・会員・有料会員）
signup.html     会員登録・ログイン
search.html     ストーリー検索・検索結果（会員のみ）
story.html      ストーリー  例：story.html#s001
                非会員：あらすじだけ表示／会員：本文・保存・コメント
note.html       わたしのノート（会員のみ・工事中）
assets/css/style.css   見た目（色・文字・レイアウト）
assets/js/data.js      表示データ（テーマ・年代・12 Steps・ストーリー）
assets/js/app.js       画面の動き（検索、しぼりこみ、保存など）
```

## ローカルで確認する方法

`index.html` をブラウザで直接開くだけで動きます。
会員ページは、会員登録画面で入力して「登録する」を押すと見られるようになります。

## データの差し替え

`assets/js/data.js` の `stories` を、コーディングシートの内容に置き換えます。
各項目はシートの列に対応しています。

| data.js の項目 | コーディングシートの列 |
|---|---|
| title | タイトル |
| worry | 子育ての悩み |
| content | 内容 |
| action | 対応方法 |
| result | 結果 |
| categories | カテゴリー（複数可） |
| keywords | キーワード（複数可） |
| comments | コメント（匿名表示。今はサンプル） |
| theme / age / step | UIのテーマ大分類・子どもの年代・12 Steps の番号 |

文章は編集せず、改行も含めてそのまま表示されます（HTMLとしては解釈せず、文字として表示）。
12 Steps の名称・説明（`steps`）と、日常語の言い換え（`synonyms`）も同じファイルで編集できます。

## 検索のしくみ

- タイトル、子育ての悩み、内容、対応方法、結果、カテゴリー、キーワード、テーマ名が対象です。
- 全角・半角、カタカナ・ひらがなの違いを区別しません。
- スペースで区切ると、すべての言葉を含むものにしぼります。
- `synonyms` に登録した言い換え（例：「うそ」「嘘」「ごまかす」）は同じ言葉として探します。

## 本番公開の前に必要なこと

この試作版の会員登録・ログインは、**ブラウザ内に登録状態を保存するだけの仮の仕組み**です。
入力内容はどこにも送信されず、ストーリーのデータも誰でも読める場所に置かれています。

本番では次の対応が必要です。

1. 会員登録・ログイン・パスワード再設定をサーバー側で実装する
   （コメントも今はブラウザ内に保存するだけなので、サーバーへの保存と、公開前の確認の仕組みが必要）
2. ストーリーのデータを会員だけが取得できる形（API など）にする
3. 有料会員の判定と決済のしくみを用意する（内容は要検討）
4. 利用規約・プライバシーポリシーのページを用意する（フッターのリンク先は現在 `#`）
5. 人物アイコン・イラストを Grow Happy さんご用意のものに差し替える

画面のデザイン（HTML / CSS）は、そのまま本番の土台として使えます。
